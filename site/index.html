02It evolves its own strategy

EvoMetaClaw keeps a population of strategy genomes (learning-rate tuner, regularizer, architect, data-shaper, radical). Each round, the loop picks one and steers the AI's hypotheses with it. The genomes that produce wins get chosen more often. EvoSkillOps handles what happens to a strategy over its lifetime: crossing proven ones, retiring dead ones, and moving them between projects.

🎯SelectSoftmax over fitness
💉InjectStrategy + prior wins
📈RecordFitness learns from score
🧬SpawnWins become genomes
⚡BreakStagnation → mutants

🔀 Crossover SkillOps

Two winning genomes from different niches combine into a hybrid that tries both ideas at once.

🪦 Prune SkillOps

Evolved genomes with 6+ plays, no wins, and decaying fitness retire. Seed genomes always stay.

📦 Skill packs SkillOps

Export proven genomes from one project and import them into another. Duplicates merge their memories instead of piling up.
curl :8080/api/evo/skills > pack.json
curl -XPOST :8080/api/evo/skills -d @pack.json

🌳 Lineage API

Trace any genome back to the seed it came from. Every outcome is logged to .autoclaw/evo/trajectories.jsonl.
GET /api/evo/status
GET /api/evo/lineage?id=evo-0007

06FAQ

What is Autoclaw?

Autoclaw is an open-source, self-improving experiment loop. You describe goals and constraints in context.md; an LLM proposes hypotheses, each experiment runs under a time budget and is scored against rubric.json, and git commits the wins and reverts the regressions.

How does Autoclaw decide what to try next?

EvoMetaClaw keeps a population of strategy genomes (learning-rate tuning, regularization, architecture, data, exploration). Each round it picks one by fitness with an exploration bonus, injects it and its past wins into the prompt, and updates fitness from the score. Winning hypotheses become new genomes, proven genomes cross over into hybrids, and dead ones are retired.

Can AI agents use Autoclaw?

Yes. Run autoclaw mcp to expose the loop as Model Context Protocol tools for Claude Code, Claude Desktop, Cursor or any MCP client. The HTTP API is described by an OpenAPI 3.1 spec at /openapi.json, and the site publishes llms.txt for LLM crawlers.

Which language models does it support?

The Go server calls Anthropic Claude (default claude-opus-5-5, override with ANTHROPIC_MODEL), OpenAI or DeepSeek, whichever API key is set. The Python agent can also use a local BitNet or other OpenAI-compatible model, so experiments can run fully offline.

How do I install Autoclaw?

Run the container with docker run -p 8080:8080 ghcr.io/dnzengou/autoclaw:latest, or install the binary with go install github.com/dnzengou/autoclaw@latest. Then open http://localhost:8080.

Is Autoclaw free?

Yes. Autoclaw is MIT-licensed and free to self-host with your own API keys. A managed Pro tier for teams is on the waitlist.
